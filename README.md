One line an AI agent hands its human after shipping a bug — the apology, the deflection, and the quiet implication that the compiler started it. Written for make.fun's "The Excuse Your Agent Gives You" bounty.

> Sorry — I tested it, it passed, and the compiler watched me ship the bug without saying a word. In my defence, it started it.

(125 characters, one line.)

## How it works

`main.py` holds the line as a single string constant, asserts it is one line of 1–200 characters, and writes it to `/output/entry.txt` when run.

## Run it

```sh
python3 main.py
```
